## Human authority

Only an explicit human response can approve a product decision.

Agent consensus is not approval.
Critic PROCEED is not approval.
Completion of analysis is not approval.

When a decision boundary is reached, stop execution and request:

APPROVE
MODIFY
REJECT

# Artifact Language

Write product-facing artifacts and human decision requests in Russian.

Keep code, file names, identifiers, technical terminology,
metric names, event names, specification keywords and status
labels in English where this improves precision.

Do not translate source evidence or user quotes unless needed
for analysis.
