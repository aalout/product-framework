# AI Product Development Template

A reusable agentic product-development environment built around:

- Cursor Agents — specialized roles and context isolation
- Agent Skills — reusable product and engineering workflows
- OpenSpec — spec-driven delivery
- Product Memory — approved decisions and validated learnings
- Human Gates — product and release accountability

## Operating Model

Signals
→ Discovery
→ Product Review
→ Human Decision
→ Experiment
→ Validated Learning
→ OpenSpec
→ Architecture
→ Implementation
→ Independent Verification
→ Release
→ Learning

## Core Principle

Agents analyze, challenge and execute.

Humans own product decisions.

Approved specifications define implementation contracts.

Validated learnings become durable product memory.
